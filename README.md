# React Hook Form + Zod 로그인 폼

React Hook Form과 Zod를 사용해 만든 간단한 로그인 폼입니다.

이메일과 비밀번호를 입력하면 형식을 확인하고, 조건에 맞지 않으면 입력창 아래에 에러 메시지가 표시됩니다. 두 값이 모두 유효하면 제출 완료 메시지가 나타납니다.

## 실행 방법

```bash
npm install
npm run dev
```

## 사용 기술

- React
- TypeScript
- React Hook Form
- Zod
